# Gerenciador de Eventos — Frontend Web (React + Vite)

Requisitos: Node.js LTS e o backend rodando em http://localhost:8080.

```bash
npm install
npm run dev
```

Abra http://localhost:5173 (use `localhost`, não `127.0.0.1`, por causa do CORS do backend).

A URL da API fica em `.env` (`VITE_API_URL`).

Rotas: `/` (Login) · `/cadastro` · `/home` (protegida por JWT).
